Entry for the make.fun bounty [One Word From Grandma](https://make.fun/bounty/u-0xkianno-one-word-from-grandma-f04bed16): exactly one word — the word a grandma would text about AI.

The word is **"robit"** — the typo a grandma makes when she means "robot".

`main.py` (pure Python standard library) writes that single word to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
